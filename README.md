# School Management System

A full-stack School Management System combining both frontend and backend in a unified monorepo.

## Project Structure

```text
├── backend/       # Node.js / Express backend API & database models
└── frontend/      # React frontend application
```

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev # or npm start
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm start
```
